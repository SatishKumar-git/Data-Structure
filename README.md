# Data Structures in C

This repository contains C programs implementing various fundamental Data Structures and Algorithms. It serves as a practical collection of basic operations like insertion, deletion, searching, and traversal.

## 📌 Topics Covered

### 1. Arrays
* Traversal, Insertion, and Deletion (Beginning, End, and Specific positions)
* Finding Maximum and Minimum elements
* Sum of all elements & Adding specific numbers
* Concatenation of two arrays
* Finding elements at even indices

### 2. Linked Lists
* Creating a Linked List
* Insertion (Beginning, End, Specific information)
* Deletion (Beginning, End, Specific information)
* Searching elements in a Linked List

### 3. Stacks & Queues
* **Stack**: Push and Pop operations using both Arrays and Linked Lists
* **Queue**: Enqueue and Dequeue operations using both Arrays and Linked Lists

### 4. Searching Algorithms
* Linear Search
* Binary Search

### 5. Matrix Operations
* Matrix Traversal
* Sum of Diagonal Elements
* Upper and Lower Triangular Matrices
